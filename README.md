# Blur CSS Generator

A React + Vite playground for crafting liquid glass, glassmorphism and neumorphism effects. Tune blur, glow and gradient parameters, preview the result in real time and export copy-paste ready snippets for native CSS or Tailwind CSS in either React or vanilla HTML formats.

## Getting started

```bash
npm install
npm run dev
```

The app runs fully client side. No build step is required for generating code – the snippets are produced directly in the browser.

## Available scripts

- `npm run dev` – launch Vite in development mode.
- `npm run build` – create a production build in `dist/`.
- `npm run preview` – preview the production build locally.
- `npm run lint` – run ESLint using the provided configuration.

## Features

- Three effect families: liquid glass, classic glassmorphism and soft neumorphism.
- Rich parameter controls for blur, saturation, highlight hue and more.
- Designer curated presets to help you get started quickly.
- Copy ready snippets for:
  - **Native CSS** – markup plus compiled CSS.
  - **Tailwind CSS** – utility-first markup with optional config hints.
- Toggle between React component code or drop-in HTML markup.
- Clipboard helpers, responsive layout and shimmering background accents inspired by [Aether CSS](https://aethercss.lovable.app/).
